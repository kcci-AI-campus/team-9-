# 프로젝트 개요 
기존 무인계산대는 상품의 바코드를 직접 스캔해야 하는 불편함이 있음
카메라 기반 객체 인식 기술을 활용하여 상품을 자동으로 인식
사용자가 상품을 카메라 앞에 보여주면 자동으로 장바구니에 추가
상품 인식부터 결제 화면까지 연결되는 무인계산대 구현

# 프로젝트 개발 목표

| 번호 | 개발 목표 | 세부 내용 |
| --- | --- | --- |
| 1 | 상품 인식 및 결제 시스템 구현 | 카메라 하나로 상품을 인식하고 결제까지 진행할 수 있는 시스템 구현 |
| 2 | 실시간 상품 객체 인식 | YOLO 기반으로 상품을 실시간 인식 |
| 3 | 장바구니 자동 추가 | 인식된 상품을 장바구니에 자동으로 추가 |
| 4 | 결제 금액 자동 계산 | 장바구니에 담긴 상품의 결제 금액을 자동으로 계산 |
| 5 | 영수증 화면 구현 | 결제 완료 후 구매 내역을 확인할 수 있는 영수증 화면 제공 |
| 6 | 간단한 사용자 조작 | 키보드 입력을 이용한 기본적인 사용자 조작 지원 |
